## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Anyone with the deployed Function URL -> attackCall | Public HTTPS callable that spends real money (ElevenLabs minutes + Twilio call charges) and places a real phone call |
| attackCall -> ElevenLabs outbound-call API | Our Function is the only caller; the destination number must never be attacker-influenced |
| Someone's likeness -> a cloned voice used to impersonate a real person | Ethical/consent boundary, not a technical one, but explicitly called out as in-scope per PROJECT.md |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-05 | Spoofing / Elevation of Privilege | attackCall onCall | medium | mitigate | Same `DEMO_TOKEN` timingSafeEqual gate as `resetDemo`, checked before the outbound `fetch`; prevents anyone with the URL from racking up ElevenLabs/Twilio charges on demand |
| T-05-06 | Tampering | `to_number` destination | critical | mitigate | `to_number` is a literal hardcoded constant (`+14015861988`) in source, never read from `req.data` or any request field -- `attackCall`'s input schema has no number-shaped field at all, so there is no code path that could dial an arbitrary number |
| T-05-07 | Repudiation / Ethics | Voice cloning without disclosed consent | high | mitigate | `ATTACKER_CONSENT.md` is written and committed BEFORE the Instant Voice Clone is created (task ordering enforces this, not just convention); the pitch (05-03) states the disclosure line on stage |
